# Amrev Consulting Group

Static one-page site selling finance advisory to African mining companies. No backend, no build step, no trackers: open `index.html` or publish the folder with GitHub Pages.

Contact details in use: email `experimentsav@gmail.com` (temporary), phone and WhatsApp `+233 25 731 9254`, office 201, Blohum Rd, Accra, Ghana, Calendly `https://calendly.com/experimentsav/30min`.

## Before launch, replace

| Placeholder | Where |
|---|---|
| `Founder Name` | About section |
| Portrait box | About section, swap for an `<img>` |
| Google Form link | Contact section, see the `GOOGLE FORM` comment (remove `hidden`) |
| Credentials | About section, each line marked `VERIFY` |
| Dashboard figures | Hero MacBook and iPhone mockups. Sample numbers, labelled "Sample data" on the page; swap for anonymised real results once you have them |

The MacBook Pro 16 and iPhone mockups are built in CSS (modelled on the Figma community files), so there are no image files to host. The laptop shows on screens wider than 760px; phones get the iPhone.

## Publish on GitHub Pages

1. Push this folder to a new repository (`index.html` at the repo root).
2. Settings, Pages, Source: deploy from branch `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repo>/`.
